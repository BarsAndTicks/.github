# Bars & Ticks

Order flow indicators for NinjaTrader 8 that explain themselves: footprint, delta, cumulative delta,
volume profile, VWAP, large trades, market structure and sessions.

- Website: https://barsandticks.com
- Free tools: https://barsandticks.com/free-tools
- Futures tick value calculator: https://barsandticks.com/tick-value-calculator
- Order flow glossary: https://barsandticks.com/glossary

The tools describe what has traded. They give no buy or sell signals and place no orders.
Futures trading involves substantial risk of loss.
